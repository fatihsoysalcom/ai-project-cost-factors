# AI Project Cost Factors

This Python script provides a simplified calculator for AI project development costs. It demonstrates how factors like project complexity, data size, team size, and development duration influence the overall budget, reflecting concepts from the article.

## Language

`python`

## How to Run

Save the code as `ai_cost_calculator.py` and run it from your terminal using: `python ai_cost_calculator.py`

This example accompanies the Turkish article: [2026’da Kurumsal Yapay Zeka Geliştirme Maliyetleri: Gerçek Projelerden Şirketlerin Ödediği Tutarlar](https://fatihsoysal.com/blog/2026da-kurumsal-yapay-zeka-gelistirme-maliyetleri-gercek-projelerden-sirketlerin-odedigi-tutarlar/).
